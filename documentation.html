5-Tier Data Resiliency & Network Fallback Strategy

To guarantee mission continuity even during severe network outages, CORS proxy failures, or upstream API rate-limits, OrbitGuard executes an automated 5-tier fallback cascade:

Tier Level Data Mechanism Protocol & Path Reliability Guarantee
Tier 1 (Primary) Local Python Daemon Cache fetch('active.tle') via server.py Zero CORS, instantaneous local disk read, refreshed every 120 minutes.
Tier 2 (Direct) CelesTrak NORAD GP https://celestrak.org/NORAD/elements/gp.php Direct upstream access when running on web hosts or permissive CORS headers.
Tier 3 (Proxies) Multi-Gateway CORS Proxy corsproxy.io, allorigins.win Rotational public bypass proxies for sandbox & static file environments.
Tier 4 (Offline) Browser localStorage window.localStorage.getItem('orbitguard_tle') Instantaneous offline cache persistence across browser restarts.
Tier 5 (Air-Gap) Hardcoded Static Ephemeris Embedded ISS, Starlink, Tiangong & Debris dataset 100% guarantee of full 3D simulation even on completely disconnected air-gapped systems.

Mathematical Formulations

3. Astrodynamics & Mathematical Foundations

SEC-03

OrbitGuard computes precise instantaneous state vectors $(\mathbf{r}, \mathbf{v})$ by integrating NORAD Two-Line Element sets via the SGP4 (Simplified General Perturbations 4) and SDP4 (Simplified Deep-Space Perturbations 4) models.

3.1 Semi-Major Axis ($a$) & Orbital Period ($T$)

Derived from the mean motion $n_0$ ($\text{rad/min}$) and Earth's standard gravitational parameter $\mu = 3.986004418 \times 10^{14} \text{ m}^3/\text{s}^2$:

T = 2π / n [seconds] a = (μ · (T / 2π)²)^(1/3) [km]

The instantaneous perigee $r_p$ and apogee $r_a$ altitudes above the mean Earth radius ($R_\oplus = 6371\text{ km}$) are:

r_p = a · (1 - e) - R_⊕ [km] r_a = a · (1 + e) - R_⊕ [km]
3.2 Perturbation Forces & Oblateness ($J_2$)

The non-spherical gravitational potential of Earth causes nodal precession ($\dot{\Omega}$) and argument of perigee rotation ($\dot{\omega}$) due to the $J_2 = 1.08263 \times 10^{-3}$ harmonic:

dΩ/dt = -(3/2) · n · J₂ · (R_⊕ / p)² · cos(i) dω/dt = (3/4) · n · J₂ · (R_⊕ / p)² · (5 · cos²(i) - 1)

Where $p = a(1 - e^2)$ is the semi-latus rectum, and $i$ is orbital inclination.

3.3 TEME to WebGL 3D Scene Scaling

Earth in the 3D globe is modeled with a radius of $R_{\text{3D}} = 54\text{ units}$. The True Equator Mean Equinox (TEME) Cartesian vectors are mapped using the scaling factor $k$:

k = R_3D / R_⊕ = 54 / 6371 ≈ 0.0084759 X_3D = X_TEME · k Y_3D = Z_TEME · k Z_3D = -Y_TEME · k

4. Conjunction Screening & B-Plane Mechanics

SEC-04

Conjunction risk assessment screens pairwise satellite interactions over a 24-hour forward propagation horizon to compute the Time of Closest Approach ($TCA$), minimum separation distance, relative encounter speed, and covariance uncertainty.

4.1 B-Plane (Target Plane) Encounter Geometry

The B-Plane is a 2D coordinate system $(\xi, \zeta)$ perpendicular to the relative velocity vector $\mathbf{v}_{\text{rel}} = \mathbf{v}_A - \mathbf{v}_B$. The 3D positional covariance matrices of both objects are projected onto the B-Plane:

d(t) = ||r_A(t) - r_B(t)|| = sqrt((x_A-x_B)² + (y_A-y_B)² + (z_A-z_B)²) TCA = argmin_{t ∈ [0, 24h]} d(t)

The 2D Gaussian probability of collision $P_c$ across the combined hard-body collision radius $R = R_A + R_B$ is computed as:

P_c = (1 / (2π · σ_ξ · σ_ζ · sqrt(1 - ρ²))) · ∬_{Disk} exp(-0.5 · Q) dξ dζ

// Fetch live TLE catalog and propagate ISS using satellite.js
async function fetchAndPropagate() {
    const res = await fetch('http://localhost:8000/active.tle');
    const rawTle = await res.text();
    const lines = rawTle.trim().split('\n');

    // Parse satellite record (3 lines: Name, Line 1, Line 2)
    const name = lines[0].trim();
    const satrec = satellite.twoline2satrec(lines[1], lines[2]);
    const now = new Date();

    // Propagate instantaneous position & velocity (ECI TEME)
    const positionAndVelocity = satellite.propagate(satrec, now);
    const gmst = satellite.gstime(now);
    const geodetic = satellite.eciToGeodetic(positionAndVelocity.position, gmst);

    console.log(`[${name}] Lat: ${(geodetic.latitude * 180/Math.PI).toFixed(2)}°, Alt: ${geodetic.height.toFixed(1)} km`);
}
fetchAndPropagate();

size_t WriteCallback(void* contents, size_t size, size_t nmemb, void* userp) {
    ((std::string*)userp)->append((char*)contents, size * nmemb);
    return size * nmemb;
}

int main() {
    CURL* curl = curl_easy_init();
    if(curl) {
        std::string readBuffer;
        curl_easy_setopt(curl, CURLOPT_URL, "http://localhost:8000/api/tle/sync");
        curl_easy_setopt(curl, CURLOPT_WRITEFUNCTION, WriteCallback);
        curl_easy_setopt(curl, CURLOPT_WRITEDATA, &readBuffer);
        curl_easy_perform(curl);
        curl_easy_cleanup(curl);
        std::cout << "Sync Response: " << readBuffer << std::endl;
    }
    return 0;
}

8. Troubleshooting & Frequently Asked Questions

SEC-08

Quick resolutions for common issues related to CORS cross-origin policies, local Python daemon execution, WebGL GPU context drops, and offline air-gapped usage.

CORS error when opening HTML files directly from filesystem (file://)
Browsers restrict fetch() requests when files are opened directly via file:///path/index.html. To resolve this:

1. Open your terminal in the project directory.
2. Run: python server.py (or ./start.sh).
3. Access the dashboard at http://localhost:8000.
Alternatively, OrbitGuard's built-in Tier 4 & Tier 5 fallback engines will automatically serve cached or hardcoded datasets if server is unavailable.
How often is the satellite ephemeris updated from CelesTrak?
The background Python server (server.py) executes a background daemon thread that queries CelesTrak every 2 hours (7,200 seconds). You can also trigger an immediate manual update at any time by clicking the "Refresh" button on any dashboard or calling GET /api/tle/sync.
3D Globe WebGL frame rate optimization on lower-end GPUs
If experiencing frame drops on integrated graphics:

• Open Settings and set "Visual Orbit Trail Count" to 150 or fewer.
• Disable "Particle Atmosphere Vortex" on the gateway screen.
• Reduce browser window resolution or toggle off antialiasing in Three.js renderer settings.
Can OrbitGuard run completely offline in an air-gapped facility?
Yes. OrbitGuard is completely self-contained. The local active.tle file holds thousands of satellite records. If offline, the application seamlessly activates Tier 4 (localStorage) and Tier 5 (embedded datasets), rendering 3D orbits and computing SGP4 coordinates without requiring any active internet connection.
